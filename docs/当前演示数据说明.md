## 4. 与初始化数据的区别

- `database/classroom_monitor.db`：当前随项目使用的运行数据库，包含本文件列出的 16 个账号和新增课程、课堂数据。
- `database/seed.sql`：从空库恢复时使用的稳定基线，包含 4 个核心演示账号、1 门课程和 1 节活动课堂，可重复导入。
- `python -m scripts.init_db`：只创建缺失表并补充最小账号、示例课程、活动课堂和统计配置，不会清空已有数据，也不会重复创建同名核心账号。

如需保留当前测试进度，应先停止 Uvicorn，再备份 `database/classroom_monitor.db` 和 `frontend/static/uploads/`。不要为了“重新初始化”直接覆盖唯一一份数据库。
