# 课堂学情监控管理系统 UI 设计规范

> 版本：2026-09-25。用于后续新增页面、答辩材料和界面维护，保持学生、教师、管理员三端视觉一致。

## 1. 设计原则

1. 业务内容优先：欢迎区保持紧凑，首屏尽快出现课堂、统计或管理内容。
2. 颜色承担语义：深蓝用于标题与横幅，青色用于主操作与选中态，绿色表示成功，橙色表示提醒，红色表示危险或严重预警，灰蓝用于普通信息。
3. 数据必须真实：趋势、环比、数量和运行状态只能来自现有接口或数据库，不为填充页面伪造指标。
4. 一次突出一个主操作：列表保留最常用按钮，停用、删除等低频操作收进“更多”菜单。
5. 响应式不是缩小桌面页：桌面使用左侧导航，平板使用顶部标签，手机使用固定底部导航和底部详情弹层。

## 2. 基础 Token

| 类型 | 规范 |
| --- | --- |
| 大卡片圆角 | 14px |
| 小卡片圆角 | 12px |
| 输入框和按钮圆角 | 10px |
| 胶囊圆角 | 999px |
| 控件最小高度 | 42px；手机导航 55px |
| 常规边框 | `#E2E8EC` |
| 卡片阴影 | `0 6px 24px rgba(15, 60, 80, .06)` |
| 页面背景 | `#F7FAFB` |
| 主标题 | 深灰蓝，24～30px |
| 正文 | 13～15px，行高不低于 1.5 |
| 辅助文字 | 11～12px，灰蓝色 |

## 3. 组件规范

### 3.1 顶部状态胶囊

- 统一使用 7px 状态点、11px 文案、34px 最小高度。
- “实时监控中”可增加最近更新时间；普通在线状态只显示状态点和简短文案。
- 成功状态使用绿色，数据同步或普通信息使用青绿色，错误状态使用红色。

### 3.2 页面 Banner

- 教师“实时课堂”是数据驾驶舱，直接进入课堂信息与统计看板，不展示欢迎 Banner。
- 教师“学情预警”和“在线讨论”属于业务处理页，保留紧凑的教师工作台 Banner；切换模块后页面回到顶部，不能把 Banner 自动滚出视口。
- 学生端和管理员端继续按各自工作台结构使用紧凑 Banner；不得因截图滚动造成同类页面规则看起来不一致。

### 3.3 卡片

- 一级业务区域使用白底、大卡片圆角、浅边框和统一阴影。
- KPI 卡只在左侧使用一条语义色，不使用整卡高饱和渐变。
- 同组卡片保持相同内边距、标题层级和最小高度。
- 学生提醒卡片优先一屏展示更多记录：桌面三项摘要同排，手机两列换行；教师意见区使用较小内边距，但正文行高不得低于 1.5。

### 3.4 表格

- 文本默认左对齐，人数、分数、方差和编号等数字右对齐，时间列使用固定宽度与等宽数字。
- 状态胶囊最小宽度 62px；同一张表的操作按钮保持相同高度。
- 高频操作直接展示，低频或危险操作放入“更多”菜单；删除必须保留二次确认。
- 长表格保留固定表头和操作列，窄屏允许表格区域内部横向滚动。
- 列表中的业务时间默认使用 `MM-DD HH:mm`；完整年份和秒数仅在详情、导出或需要审计精度时展示。

### 3.5 空状态

- 统一由图标、标题、说明和可选引导动作组成。
- 标题说明“当前没有什么”，辅助文字说明“用户下一步可以做什么”。
- 空状态不展示虚假示例记录。
- 空状态与真实数据必须互斥：列表存在一条或以上记录时，空状态元素必须同时在视觉和辅助功能树中隐藏。

### 3.6 抽屉与弹层

- 桌面端详情从右侧打开，手机端从底部打开。
- 抽屉必须提供明确关闭按钮并支持 Escape；关闭后焦点返回原触发按钮。
- 模态抽屉打开后，`Tab` 与 `Shift+Tab` 焦点必须限制在抽屉内部；必填项失败时应显示就地错误文字并把焦点移回字段。

### 3.7 在线讨论

- 不直接暴露浏览器原生文件按钮。图片选择使用统一的“上传图片”组件，默认显示格式与 5 MB 限制；选择后显示文件名和移除按钮。
- 当前用户消息位于右侧并使用浅青背景；他人消息位于左侧，学生消息使用灰白背景，教师消息使用白底与绿色“教师”标签。
- 气泡必须保留发送人、角色和时间，不能只依赖颜色区分身份。
- 浏览信息与提交表单分区展示，已处理记录保持只读。

## 4. 响应式规范

- 1024px 及以上：左侧固定功能导航，业务内容位于右侧。
- 701～1023px：功能导航位于页面顶部，卡片按可用宽度换行。
- 700px 及以下：固定底部导航，使用短标签“课堂、提醒、讨论、历史、退出”等；正文底部至少预留 126px 加安全区域。
- 手机欢迎区高度控制在约 138px；课堂信息使用两列布局，长字段整行展示。
- 所有可点击控件保证可见、可聚焦，不被底部导航遮挡。

## 5. 数据可视化规范

- 柱状图用于比较当前六档人数，折线图用于表达最近周期变化。
- 图表颜色与六档反馈颜色一致，并提供文字或 ARIA 摘要。
- 没有完整周期时显示真实空状态，不补零制造趋势。
- 方差同时提供“较低、适中、较高”的业务解释，但保留原始数值供核对。

## 6. 页面维护检查

新增或修改页面后，应检查桌面和 390×844 手机视口、键盘焦点、状态色语义、空状态、长文本、表格滚动、减少动态效果偏好，并重新生成用户手册引用的截图。视觉调整不得改变权限、统计口径、数据库约束或新增业务模块规则。
